## Variant-specific changes and limits

- **B adds E06-067:** The incoming customer email gives a 5 L cap diameter and height (`D = 50.2`, `h = 21.3`). B translates the event to English and returns 0.39 (NO); A, C, and D do not list it as an error. This is a new false negative, but does not show that translation caused it: the event content, call, and time all differ from the saved A response (`benchmark_E06.json:31-39`; `inputs/B.json:27-33`; `raw_responses/B.json:39-46`; `metrics.json:24-29,103-110`; `diagnostic_plan.json:59-63`).
- **C fixes E06-193:** Its score is 0.33 (NO), versus A 0.51, B 0.73, and D YES at 0.58. C's isolated planned input change is a speaker field derived from event direction, so the shift supports checking attribution. Yet E06-192 on the same deal remains wrong even with `speaker=SELLER`; a whole-event field cannot separate quoted customer text from seller-authored text (`raw_responses/B.json:685-692`; `raw_responses/C.json:685-692`; `raw_responses/D.json:885-894`; `inputs/C.json:513-530`; `five_error_matrix.md:10-11`).
- **The one-example gain is not meaningful evidence of a general improvement.** C moves from A's 36/41 to 37/41, a 2.4 percentage-point difference on this fixed sample. The five baseline errors span four deals: E06-075 / deal 18755, E06-078 / 18731, E06-179 / 6885, and E06-192 plus E06-193 / 7601. B's extra E06-067 is also deal 18731. These within-deal examples are correlated; counting 41 events as independent would overstate the evidence (`benchmark_E06.json:33,145,187,369,551,565`; `metrics.json:16,95,179,255`).
- **Confounds:** B changes Russian event content to English, so translation fidelity and wording may matter. C derives one speaker label from event direction: that is plausible for a single-sender email, but it labels all of the mixed-speaker E06-179 call CUSTOMER and all text in quoted email threads as one speaker (`diagnostic_plan.json:59-63`; `inputs/C.json:344-348,513-530`). A is a saved response with no new call, while B/C/D are current calls; without repeated calls, stochastic or time effects remain mixed with the variant changes. D also changes the answer format to Choice A/B, so it is not a pure repetition of Noul scoring (`diagnostic_plan.json:59-63`; `raw_responses/B.json`; `raw_responses/C.json`; `raw_responses/D.json`).

## Disputed examples — excluded from the 41 scored cases

- **E06-076:** “цилиндрическая” (“cylindrical”) gives a shape but no visible referent or checkable requirement in this event. All variants return NO: A 0.20, B 0.13, C 0.29, D Choice B. A missing prior reference could change interpretation (`benchmark_E06.json:157-165`; `metrics.json:77-85,161-169,238-246,271-278`).
- **E06-077:** “На всех ведрах так приклеены этикетки” (“labels are glued onto all buckets like this”) refers to an absent “this way” antecedent or visual. All variants return NO: A 0.24, B 0.40, C 0.27, D Choice B. Preserve the supplied dispute; these model answers do not resolve it (`benchmark_E06.json:171-180`; `metrics.json:77-85,161-169,238-246,281-286`).

The audit supports only a narrow observation: explicit speaker metadata coincided with one corrected seller-authored email, while translation coincided with one added miss. Repeated runs and speaker-aware treatment of quoted or multi-speaker content would be needed to separate those effects.
