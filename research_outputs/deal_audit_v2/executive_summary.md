# Executive summary — dataset v2

**Статус: готов к использованию для следующей пересборки downstream research dataset.** Hard gate пройден: среди 337 звонков с измеренной длительностью ≥36 сек transcript есть у всех; eligible без transcript — 0. В dataset остаются 343 звонка без доступного audio/измеренной длительности — это ограничение качества данных, не отрицательные свидетельства.

Для всех 23 сделок создан outcome-blind final audit: семь изменившихся представлений переаудированы, 16 неизменившихся используют замороженный аудит v1. Хэши финальных аудитов проверены до присоединения меток WON/LOST. Manifest не изменился; выборка по-прежнему 12 WON и 11 LOST. Старый dataset и research_outputs/deal_audit_v1 сохранены.

Ключевое изменение бизнес-интерпретации — сделка 18755: восстановленный transcript напрямую подтверждает ценовой разрыв и сравнение с более дешёвыми вариантами (view, строка 51, activity_id 635353). Поэтому паттерн прямого сравнения предложения теперь включает 5/11 LOST вместо 4/11; остальные memberships не изменились. Это наблюдаемая связь, не доказательство причины проигрыша.

Итог WON vs LOST остаётся ограниченным ретроспективным наблюдением по 23 сделкам одного менеджера. Причинный или предиктивный эффект и рост конверсии не установлены. Состав паттернов — taxonomy.json; агрегат с показателями звонков — won_vs_lost.json; полный diff — delta_comparison.json.
