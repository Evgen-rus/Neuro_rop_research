Jev — специализированная модель/система для быстрых массовых
семантических решений по заданному вопросу.

Используем не для:
- общего анализа сделки;
- генерации рекомендаций;
- длинного reasoning;
- поиска новых паттернов.

Используем для уже сформулированных атомарных проверок:

boolean:
"Есть ли конкретный клиентский следующий шаг?"

choice:
"Что произошло с последним клиентским обязательством?"

ordinal:
"Насколько определён внутренний процесс решения?"

Хороший Jev classifier:
- один конкретный смысловой вопрос;
- небольшой набор ответов;
- ответ выводится из данного контекста;
- одинаково применим к тысячам сделок;
- не требует общей стратегии или длинного анализа.

Логику, которую можно точно посчитать кодом, Jev не выполняет.

Пример:
Jev определяет:
"Было ли обещание клиента конкретным?"

Код считает:
"Сколько таких обещаний подряд было сорвано?"

Цель:
Jev = дешёвый массовый semantic sensor.
NeuroROP/LLM = глубокий анализ только там, где sensor нашёл сигнал.
